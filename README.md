# CS201 - Introduction to Programming Assignments (First Semester)

## 📖 Overview
This repository holds the **first assignment** for the *CS201 – Introduction to Programming* course (First Semester).  It demonstrates basic C++ concepts such as:
- Standard I/O with `iostream` and `iomanip`
- Simple arithmetic and digit extraction
- Formatted console output using manipulators (`setw`, `left`)
- Conditional logic to compute attendance standing (CLEARED, WARNING, DETAINED)

The program prints student details, extracts digits from the student ID, and generates a formatted attendance report for five courses.

## 📂 Repository Contents
- `main.cpp` – The source code for the assignment.
- `Spring 2026_CS201_1.docx` – Assignment brief and specifications.
- `main.exe` – Pre‑compiled binary (Windows).

## ⚙️ Build & Run
```bash
# Compile (requires a C++ compiler, e.g., g++)
g++ -std=c++17 -O2 main.cpp -o assignment1
# Execute
./assignment1
```
On Windows you can also run the provided `main.exe` directly.

## 🎯 Learning Goals
- Practice basic C++ syntax and standard library usage.
- Learn to format console output for tables.
- Apply simple control‑flow statements to compute derived data.
